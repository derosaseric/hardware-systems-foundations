# Hardware Systems Foundations

A hands-on learning repository focused on building strong low-level
software and hardware fundamentals for embedded systems, computer
architecture, hardware security, FPGA development, and performance
engineering.

## Current Focus

Phase 1 - C and Low-Level Foundations

Currently studying:

- C programming
- Linux command-line development
- Git and GitHub
- Binary and hexadecimal representation
- Bitwise operations and bit masks
- Functions and program structure
- Input validation
